# Avenger 5 UAS Grounded Interface Matrix (Physical, Power, Bus, Discrete, Mechanical, RF)

Source Baseline: Synthesized exclusively from `01_avenger5_platform_and_architecture.md` through `05_engineering_gaps_and_synthesis_ledger.md` under Step 0.0 (Level 0 OEM Ground Truth Ingestion).

Architectural Boundary Notes:
- **Zero Electrical / CAN Interface to PL-40**: The `ELI PL-40` launcher has strictly mechanical rail/carriage engagement with the airframe (`IF-MECH-001`). There is zero umbilical CAN, power, or discrete cable between `PL-40` and the UAV; launch acceleration (`SS1`) is sensed onboard by the `ESAD` and `Cube orange+` IMU.
- **No Standalone RTA Hardware Box**: Mission supervision and `ESAD` bridging execute on `RPI CM5004032` and flight stabilization executes on `Cube orange+` inside `ASTK A5 V2.5`.
- **Sensor Board Supply (`J102 -> J1`)**: Per `04_esad_excalibur_icd.md#p10-#p13`, `J102 -> J1` carries `5V0` (`VOUT`, 2 pins), `GND` (2 pins), `DIST_COMM1/2`, `IRQ_L <-> IR_ESAD_L`, and `DIST_SPARE`.

## 2. ESAD RS-485 Protocol Command & Frame Summary (`04_esad_excalibur_icd.md`)

Packet Framing (`Table 8`): `[Length (1 B, min 5)] [Header (1 B: 0x01 OC->ESAD, 0x02 ESAD->OC)] [Command (1 B)] [Data (0..9 B)] [CRC-16 XModem (2 B, init 0x0000, poly 0x1021)]`.

| Opcode | Command | Direction | Frame Semantics & Safety Bitfields | OEM Source Citation |
| :--- | :--- | :--- | :--- | :--- |
| `0x10` | `EXCHANGE` | `OC <-> ESAD` | Request `0x08` bytes (`OC_Status` bits 0-5: `Fault Mode`, `Simulation Mode`, `Arm Enable`, `Mission Abort Enable`, `Arm Abort Enable`, `OC Trigger Enable`; `SimAccelerationOffset`); Response `0x0E` bytes (`ArmState` `0..5`, `FaultStates` `UINT16` bits 0-8, `FlightTimer` `1 s/LSB`, `Acceleration` `0.0039 g/LSB`) | `[ESAD ICD_for Excalibur_AB00-0054-01AA-0005 2 1.pdf#p17]`-`[#p23]` |
| `0x11` | `PBIT` | `OC <-> ESAD` | Request `0x05` bytes; Response `0x07` bytes; Power-on Built-In Test including bit 12 internal HV safe check (`< 50 V` safe vs `>= 50 V` fault) | `[ESAD ICD_for Excalibur_AB00-0054-01AA-0005 2 1.pdf#p17]`-`[#p18]`, `[#p26]`-`[#p27]` |
| `0x12` | `HIGHVOLTAGE` | `OC <-> ESAD` | Request `0x05` bytes; Response `0x08` bytes; returns `UINT8` flags (`SS1/SS2/DS Enabled & Sensed`, `Charger Enabled`, `HV Charged`) + `UINT16 Value` `[0, 1800] V` (`1 V/LSB`) | `[ESAD ICD_for Excalibur_AB00-0054-01AA-0005 2 1.pdf#p17]`-`[#p18]`, `[#p26]`-`[#p27]` |
