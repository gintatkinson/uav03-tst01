# Avenger 5 UAS Grounded Bill of Materials (OEM BOM)

Source Baseline: Synthesized exclusively from `01_avenger5_platform_and_architecture.md` through `05_engineering_gaps_and_synthesis_ledger.md` under Step 0.0 (Level 0 OEM Ground Truth Ingestion).

Scope Note: Production Avenger 5 (`Avenger V2.5` / `ASTK A5 V2.5`) excludes recovery parachutes (`Recovery System: No`); the `2x` pyrotechnic recovery igniters (`BOM-AV-026`) are explicitly flagged `Optional RnD`. The `PL-40` pneumatic launcher has zero electrical/CAN wire to the airframe (`IF-MECH-001`), and there is no standalone RTA hardware box (supervision runs on `RPI CM5004032` + `Cube orange+`).
