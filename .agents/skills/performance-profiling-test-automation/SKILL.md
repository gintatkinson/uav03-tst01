# Performance, RMA & Verification Automation (`deap03`)

Use this skill to verify real-time deterministic schedulability, bounded stack/memory budgets, bounded formal proofs (`verification/mission-kani/src/generated/`), and (when a Ring-3 HMI exists under `app_flutter/`) 60 FPS frame-budget compliance against live persistence.

## 1. Real-Time Embedded & `#![no_std]` Contracts (Rings 1 & 2)

1. **RMA Utilization & WCRT Alignment (`RAAML::RTA`)**:
   - Cross-check periodic task budgets declared in `schema/<domain>/` (`@RmaTask { priority, wcetS, blockingS, periodS, deadlineS }`) using `RAAML::RTA::RmaUtilization` and `RAAML::RTA::RmaWcrtBound`.
   - Confirm total effective processor utilization `U_eff` remains below the Liu-Layland / priority-ceiling schedulability threshold and `WCRT <= deadlineS` for every safety-critical loop (`ESAD` interlocks, flight control inner loop, RTA Simplex monitor).
2. **Zero Heap Allocation & Zero Panic Paths**:
   - Audit `#![no_std]` Ring-1/Ring-2 crates (consuming `crates/mission-contracts/src/generated`) for absence of heap allocation (`alloc`), recursion, unbounded loops, and panic-inducing slice indexing or unchecked division.
3. **Dual-Track Numerical & Timing Equivalence**:
   - Execute offline Rust digital twin unit/property tests verifying trajectory error `<= 10^-6`, zero NaN/Inf propagation, and deterministic state transitions under fault injection.

## 2. Bounded Model Checking (`verification/mission-kani/src/generated/`)

Validate synthesized proof harnesses generated by `./.deap/bin/compile-sysml build --out-contracts crates/mission-contracts/src/generated --out-kani verification/mission-kani/src/generated`:

```sh
cargo test --workspace && echo "CARGO_TESTS: PASS"
./.deap/bin/verify-baseline hygiene --workspace . --perimeter-role downstream-consumer --schema-scope all && echo "HYGIENE: PASS"
```

When `cargo kani` is installed on the host workstation, run the bounded proof harnesses emitted under `verification/mission-kani/src/generated/` against safety invariants (`pCatBound`, `PhaseMarginEff`, ZCBF barrier flux `phiCbf`, ESAD arming interlock invariants) and record exact raw outputs without relaxing assertions.

## 3. Ring-3 GCS HMI 60 FPS Profiling (Conditional on `app_flutter/`)

When a Flutter Ground Control Station HMI exists under `app_flutter/`:
1. **Zero-Mocking Live Persistence Mandate**: Seed a real SQLite/local emulator database per `downstream-profiles/profile-target-app-runtime/PERSISTENCE_ARCHITECTURE_BLUEPRINT.md` and `downstream-profiles/profile-dart-flutter-hmi/SAFETY_CRITICAL_REALTIME_UI_BLUEPRINT.md` with realistic node/telemetry density; in-memory production mocks are forbidden. Tear down seeded test state cleanly after profiling.
2. **Trace Execution**: Wrap telemetry burst, viewport pan/zoom, and alert-panel interactions inside `WidgetTester.traceAction()`.
3. **Strict 60 FPS Frame Budgets**: Fail the regression suite if any threshold is exceeded:
   - Average frame build time: `< 16.0 ms`
   - 90th percentile frame build time: `< 16.6 ms`
   - Average frame rasterizer time: `< 16.0 ms`
4. **Verification Commands**:

```sh
flutter analyze && flutter test && echo "FLUTTER_TESTS: PASS"
flutter drive --driver=test_driver/integration_test.dart --target=integration_test/viewport_perf_test.dart -d macos --profile && echo "FLUTTER_PROFILE: PASS"
```
